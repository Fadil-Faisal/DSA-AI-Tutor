1. Backend Overview
The backend for the Adaptive DSA Tutor Agent is built entirely using Next.js 14 API Routes — no separate Express or NestJS server is needed. All routes live under app/api/ and are deployed as serverless functions on Vercel's free tier.
This document is the complete backend implementation guide for Fadil Faisal. It covers every API route, the AI decision engine, Groq + Gemini integration, the two-stage explanation mode system, the database schema, Supabase Realtime for multiplayer, Judge0 code execution, and security considerations.
2. Backend Architecture
No dedicated backend server. All logic runs as Next.js serverless API routes. Supabase handles the database, auth (optional), and Realtime WebSocket channels for multiplayer.
Request Flow:
  Browser (React)  →  Next.js API Route  →  Groq / Gemini API
                            ↓                       ↓
                     Supabase DB  ←──── AI response processed
                            ↓
                    Response to Browser
Multiplayer Flow:
  Student A  →  Supabase DB update (room_members.current_code)
                     ↓
              Supabase Realtime broadcasts change
                     ↓
  Student B  ←  Receives update via WebSocket subscription

4. The Two-Stage Explanation System (Backend Implementation)
Every API route that calls an AI model must accept and handle the explanationMode field ('simple' | 'complex'). This mode modifies the AI system prompt to produce age-appropriate output.
4.1 Persona Prompts
// lib/agent/prompts.ts
export function getModePersona(mode: 'simple' | 'complex'): string {
  if (mode === 'simple') {
    return `
      You are explaining to a 10-year-old who is just starting to learn programming.
      Rules:
      - Use ZERO technical jargon. Replace every CS term with a real-world analogy.
      - Arrays = 'a row of numbered boxes'
      - Recursion = 'a mirror looking at a mirror'
      - Pointers = 'a sticky note that tells you where something is'
      - Keep sentences short. Max 2 lines per paragraph.
      - Always end with an encouraging sentence.
    `;
  }
  return `
    You are explaining to a 20-year-old CS student preparing for technical interviews.
    Rules:
    - Use precise CS terminology: O(n), amortized complexity, in-place, stable sort.
    - Reference standard algorithms by name (Dijkstra, BFS, Kadane's algorithm).
    - Discuss time/space complexity tradeoffs.
    - Mention edge cases and corner cases explicitly.
    - Assume knowledge of basic data structures.
  `;
}

5.1 POST /api/agent — Core Decision Engine
The most important route. Decides what problem to give the student next, generates the reasoning panel text. Uses Gemini for deep reasoning.
Request Body
{
  sessionId: string,
  explanationMode: 'simple' | 'complex',
  confidence: {
    arrays: number, trees: number, graphs: number,
    dp: number, recursion: number, sorting: number,
    searching: number, strings: number, heaps: number, linked_lists: number
  },
  lastAttempt?: {
    problemId: string,
    topic: string,
    correct: boolean,
    timeTaken: number,
    mistakePattern?: string
  }
}
Response
{
  problem: Problem,          // Next problem to show
  reasoning: string,         // Plain English: why this problem was chosen
  decision_type: string,     // 'next_problem' | 'review' | 'new_topic'
  confidence_update?: { topic: string, delta: number }
}
Implementation
// app/api/agent/route.ts
import { NextRequest, NextResponse } from 'next/server';
import { geminiChat } from '@/lib/agent/gemini';
import { getModePersona } from '@/lib/agent/prompts';
import { supabaseServer } from '@/lib/supabase/server';
export async function POST(req: NextRequest) {
  const { sessionId, explanationMode, confidence, lastAttempt } = await req.json();
  // 1. Find weakest topic
  const weakestTopic = Object.entries(confidence)
    .sort(([, a], [, b]) => a - b)[0][0];
  // 2. Check spaced repetition — topics not seen in 48 hours
  const { data: recentAttempts } = await supabaseServer
    .from('problem_attempts')
    .select('topic, created_at')
    .eq('session_id', sessionId)
    .order('created_at', { ascending: false })
    .limit(20);
  // 3. Build Gemini prompt with full context
  const persona = getModePersona(explanationMode);
  const prompt = `
    ${persona}
    You are an AI tutor deciding what DSA problem to give a student next.
    Student confidence scores: ${JSON.stringify(confidence)}
    Weakest topic: ${weakestTopic}
    Last attempt: ${JSON.stringify(lastAttempt)}
    Recent topics: ${JSON.stringify(recentAttempts?.map(a => a.topic))}
    Decide: which topic and difficulty to give next.
    Explain your reasoning in 2-3 sentences (for the reasoning panel).
    Respond in JSON: { topic, difficulty, reasoning, decision_type }
  `;
  const aiResponse = await geminiChat(prompt);
  const parsed = JSON.parse(aiResponse);
  // 4. Fetch matching problem from database
  const { data: problem } = await supabaseServer
    .from('problems_bank')
    .select('*')
    .eq('topic', parsed.topic)
    .eq('difficulty', parsed.difficulty)
    .limit(1)
    .single();
  // 5. Log agent decision
  await supabaseServer.from('agent_decisions').insert({
    session_id: sessionId,
    decision_type: parsed.decision_type,
    reasoning: parsed.reasoning,
  });
  return NextResponse.json({ problem, reasoning: parsed.reasoning });
}

  feedback: string,           // Mode-adapted explanation
  mistakePattern?: string,    // e.g. 'off_by_one', 'wrong_base_case'
  timeComplexity?: string,    // Only in complex mode
  spaceComplexity?: string,   // Only in complex mode

Mistake Pattern Detection
After evaluation, the route classifies the mistake into one of five named patterns. After 3 occurrences of the same pattern, a personalized mental model fix is generated.
Implementation
// app/api/evaluate/route.ts
import { groq, GROQ_FAST } from '@/lib/agent/groq';
import { getModePersona } from '@/lib/agent/prompts';
export async function POST(req: NextRequest) {
  const { sessionId, problemId, code, language,
          explanationMode, timeTaken, attemptsCount } = await req.json();
  // Fetch correct solution from DB
  const { data: problem } = await supabaseServer
    .from('problems_bank').select('*').eq('id', problemId).single();
  const persona = getModePersona(explanationMode);
  const completion = await groq.chat.completions.create({
    model: GROQ_FAST,
    messages: [{
      role: 'system',
      content: `${persona} You are a DSA tutor evaluating a student's solution.`
    }, {
      role: 'user',
      content: `
        Problem: ${problem.title}
        Correct solution: ${problem.solution}
        Student's ${language} code: ${code}
        Time taken: ${timeTaken}s, Attempts: ${attemptsCount}
        Evaluate: is the solution correct?
        If wrong: what is the mistake pattern? (off_by_one / null_check_missing /
          wrong_base_case / wrong_algorithm / visited_not_marked)
        Generate feedback in the appropriate explanation mode.
        JSON: { correct, feedback, mistakePattern, timeComplexity, spaceComplexity }
      `
    }],
    response_format: { type: 'json_object' }
  });
  const result = JSON.parse(completion.choices[0].message.content!);
  // Update learner model
  const confidenceDelta = result.correct ? 0.1 : -0.05;
  await updateConfidence(sessionId, problem.topic, confidenceDelta);
  // Log attempt
  await supabaseServer.from('problem_attempts').insert({
    session_id: sessionId, problem_id: problemId,
    topic: problem.topic, attempts_count: attemptsCount,
    time_taken_seconds: timeTaken,
    final_status: result.correct ? 'solved' : 'in_progress',
    mistake_pattern: result.mistakePattern ?? null
  });
  return NextResponse.json(result);
}
5.3 POST /api/hint — Progressive Hint Generator
Generates one of three escalating hints per problem. Hints are always targeted to the specific mistake pattern if one is known. Mode-adapted language throughout.
Request Body
{
  sessionId: string,
  problemId: string,
  hintLevel: 1 | 2 | 3,       // Which hint to generate
  explanationMode: 'simple' | 'complex',
  currentCode?: string,        // Student's current code for targeted hints
  mistakePattern?: string      // Known mistake pattern from last eval
}
Hint Level Rules
// app/api/hint/route.ts
export async function POST(req: NextRequest) {
  const { problemId, hintLevel, explanationMode,
          currentCode, mistakePattern } = await req.json();
  const { data: problem } = await supabaseServer
    .from('problems_bank').select('hints, solution, title').eq('id', problemId).single();
  // First try pre-written hints from DB (faster, cheaper)
  if (problem.hints[hintLevel - 1] && !mistakePattern) {
    return NextResponse.json({ hint: problem.hints[hintLevel - 1] });
  }
  // Generate targeted hint via Groq if mistake pattern known
  const persona = getModePersona(explanationMode);
  const levelDescriptions = {
    1: 'a small nudge — no approach revealed',
    2: 'the high-level approach — no code',
    3: 'pseudocode — near complete but not runnable'
  };
  const completion = await groq.chat.completions.create({
    model: GROQ_FAST,
    messages: [{
      role: 'system', content: `${persona} Generate a Level ${hintLevel} hint.`
    }, {
      role: 'user',
      content: `
        Problem: ${problem.title}
        Student code so far: ${currentCode ?? 'not provided'}
        Known mistake pattern: ${mistakePattern ?? 'none'}
        Hint level: ${hintLevel} (${levelDescriptions[hintLevel as 1|2|3]})
        Generate the hint in JSON: { hint: string }
      `
    }],
    response_format: { type: 'json_object' }
  });
  const { hint } = JSON.parse(completion.choices[0].message.content!);
  return NextResponse.json({ hint });
}

Confidence Update Logic
// lib/agent/confidence.ts
export function calculateConfidenceDelta(
  current: number,
  correct: boolean,
  timeTaken: number,
  attemptsCount: number
): number {
  if (correct) {
    // Reward: more reward for fast, first-attempt solves
    const speedBonus = timeTaken < 120 ? 0.05 : 0;     // < 2 min = fast
    const attemptPenalty = attemptsCount > 2 ? -0.02 : 0;
    return Math.min(0.15 + speedBonus + attemptPenalty, 0.20);
  } else {
    // Penalty: small — we don't want to discourage
    return -0.05;
  }
}
// Clamp confidence between 0.0 and 1.0
export const clampConfidence = (v: number) => Math.max(0, Math.min(1, v));
5.5 POST /api/execute — Judge0 Code Execution
Proxies code execution to Judge0 CE (free, public). Supports Python, Java, C++, and JavaScript. Returns stdout, stderr, and compile errors.
Judge0 Language IDs
// app/api/execute/route.ts
export async function POST(req: NextRequest) {
  const { code, language, testCases } = await req.json();
  const languageIds: Record<string, number> = {
    python: 71, java: 62, cpp: 54, javascript: 63
  };
  const results = await Promise.all(testCases.map(async (tc: any) => {
    const submission = await fetch(
      `${process.env.NEXT_PUBLIC_JUDGE0_URL}/submissions?base64_encoded=false&wait=true`,
      {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          source_code: code,
          language_id: languageIds[language],
          stdin: tc.input,
          expected_output: tc.expectedOutput,
        })
      }
    );
    return submission.json();
  }));
  return NextResponse.json({
    results: results.map(r => ({
      passed: r.status.id === 3,  // 3 = Accepted
      stdout: r.stdout,
      stderr: r.stderr,
      compile_output: r.compile_output,
      time: r.time,
      status: r.status.description
    }))
  });
}

8. Key Helper Functions
8.1 Update Confidence (lib/agent/confidence.ts)
export async function updateConfidence(
  sessionId: string,
  topic: string,
  delta: number
): Promise<void> {
  const columnName = `${topic}_confidence`;
  // Fetch current value
  const { data } = await supabaseServer
    .from('learner_profiles')
    .select(columnName)
    .eq('session_id', sessionId)
    .single();
  const currentValue = data?.[columnName] ?? 0.5;
  const newValue = Math.max(0, Math.min(1, currentValue + delta));
  await supabaseServer
    .from('learner_profiles')
    .update({ [columnName]: newValue, updated_at: new Date().toISOString() })
    .eq('session_id', sessionId);
}
8.2 Spaced Repetition Check (lib/agent/spaced.ts)
// Returns topics that haven't been practiced in 48+ hours
export async function getDueTopics(sessionId: string): Promise<string[]> {
  const cutoff = new Date(Date.now() - 48 * 60 * 60 * 1000).toISOString();
  const { data } = await supabaseServer
    .from('problem_attempts')
    .select('topic')
    .eq('session_id', sessionId)
    .gt('created_at', cutoff);
  const recentTopics = new Set(data?.map(r => r.topic));
  const allTopics = ['arrays','trees','graphs','dp','recursion',
    'sorting','searching','strings','heaps','linked_lists'];
  return allTopics.filter(t => !recentTopics.has(t));
}
8.3 Mistake Pattern Aggregator
// Returns the most frequent mistake pattern for a session
export async function getTopMistakePattern(
  sessionId: string
): Promise<string | null> {
  const { data } = await supabaseServer
    .from('problem_attempts')
    .select('mistake_pattern')
    .eq('session_id', sessionId)
    .not('mistake_pattern', 'is', null);
  if (!data?.length) return null;
  const counts: Record<string, number> = {};
  data.forEach(r => {
    if (r.mistake_pattern) {
      counts[r.mistake_pattern] = (counts[r.mistake_pattern] ?? 0) + 1;
    }
  });
  return Object.entries(counts).sort(([,a],[,b]) => b - a)[0]?.[0] ?? null;
}
9. Error Handling & API Resilience
The primary AI is Groq. Gemini is the fallback for complex reasoning routes. If both fail, return a graceful error — never crash the frontend.
// lib/agent/withFallback.ts
export async function withFallback<T>(
  primary: () => Promise<T>,
  fallback: () => Promise<T>,
  defaultValue: T
): Promise<T> {
  try {
    return await primary();
  } catch (primaryError) {
    console.error('Primary AI failed:', primaryError);
    try {
      return await fallback();
    } catch (fallbackError) {
      console.error('Fallback AI failed:', fallbackError);
      return defaultValue;
    }
  }
}
// Usage in a route:
const result = await withFallback(
  () => groqCall(prompt),
  () => geminiChat(prompt),
  { reasoning: 'Agent is thinking...', problem: defaultProblem }
);

Route | Effect of Mode
/api/agent | Mode injected into system prompt for problem selection reasoning. Simple: agent explains why in plain language. Complex: agent references complexity, interview frequency, pattern types.
/api/evaluate | Mode controls feedback tone. Simple: 'Great try! Here is what happened step by step.' Complex: 'Your solution has O(n²) time complexity. Consider optimizing with a hash map for O(n).'
/api/hint | Mode controls hint vocabulary. Simple: analogies and real-world comparisons. Complex: algorithmic approach, pseudocode, complexity hints.
/api/interview | Mode controls interviewer persona. Simple: encouraging, patient interviewer. Complex: strict, time-pressured FAANG-style interviewer.
Pattern Name | What It Means
off_by_one | Loop boundary errors — iterating one index too far or too short
null_check_missing | Failing to handle null/None input or empty structures
wrong_base_case | Incorrect recursion termination condition
wrong_algorithm | Chose a fundamentally incorrect approach (e.g. DFS where BFS needed)
visited_not_marked | In graph problems — not tracking visited nodes, causing infinite loops
Level | Rules
Level 1 — Nudge | A small directional clue. Does NOT reveal approach. Simple: real-world analogy. Complex: mentions relevant data structure or pattern name.
Level 2 — Approach | Reveals the high-level strategy. Simple: step-by-step explanation with example. Complex: algorithm name + why it applies + complexity hint.
Level 3 — Pseudocode | Near-complete solution in plain pseudocode. Simple: written like instructions, not code. Complex: proper pseudocode with loop/condition structure.
